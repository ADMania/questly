# Questly 🎲

**Questly** — это генератор случайных заданий и приключений для каждого дня.
Проект создан как лёгкий и весёлый способ попробовать что-то новое и добавить немного неожиданности в повседневность.

## 🚀 Функционал
- 🎯 Случайная генерация заданий
- 🌙 Категории: ночные, дневные, социальные, креативные, домашние и другие
- ⚡ Уровни сложности: easy / medium / hard
- 📱 Удобный веб-интерфейс (Next.js)

## 🛠️ Технологии
- [Next.js](https://nextjs.org/) — фронтенд
- [TailwindCSS](https://tailwindcss.com/) — стилизация
- JSON-бэкенд с квестами
